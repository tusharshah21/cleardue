### Deviations from the brief
- Postgres everywhere (Docker locally on port 5433), not SQLite. Prisma can't switch providers per environment. Port 5433 because this machine already runs a native Postgres 18 on 5432.
- Prisma pinned to 7.10.1: npm's `latest` tag currently points at an 8.0 release candidate.
- Next.js `cacheComponents` turned off. Every page is per-user and request-time, and Cache Components would force Suspense boundaries around every session read for no benefit here.
- Mandate "latest acceptable final payment date" is stored as `maxPlanDays` (days after the original due date) so it works as a global default; an absolute date doesn't. It can still be shown as a date in the UI.
- Mandate fields (including autopilot and never-auto-contact) live in one JSON column validated by Zod, with client overrides merged field by field, instead of separate columns.
- Freelancer-initiated invoice creation (Flow A) doesn't go through the mandate check. The mandate governs agent-initiated actions; every agent money action will.
- shadcn's current default style uses Base UI rather than Radix; native `<select>` is used in forms.
- Not deployed to Render yet: it needs the GitHub repo pushed (you handle pushes).

### Known issues / risks
- Sandbox not exercised yet: every PayPal call is mocked-only until `PAYPAL_CLIENT_ID`/`SECRET` are in `.env`. Plan: run `npm run paypal:spike` as soon as they are, then `npm run seed:paypal`.
- Backdated demo invoices: the seed sends overdue invoices with past `invoice_date` and `due_date`. PayPal may reject a past due date. Plan: if it does, send with near-future dates and backdate locally only (the overdue story lives in our DB and timeline), and say so in the README.
- IN-country sandbox account may be unable to invoice in USD or receive sandbox payments. Plan: the spike tells us; the US-account fallback keeps `Freelancer.country = IN` so strategy selection is unchanged.
- `remind` `additional_recipients` delivery is unconfirmed. Plan: after the spike, check Sandbox Notifications for the AP address before building `awaiting_approval` on it. If it doesn't deliver, fall back to re-sending with the AP contact added as an additional recipient, or an Outbox message carrying the PayPal link.
- Login has no rate limiting (single demo account). Low impact; can be added with the pay-chat limiter in Milestone 3.
